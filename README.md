# The BR01 Restaurant — website concept

This is a responsive, frontend-only Next.js site using local, high-resolution image assets. No custom backend is required for this concept.

## Run locally
1. Install Node.js 20.9 or newer.
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Build a static site
Run `npm run build`. The static site is exported to `out/` and can be hosted on Vercel or another static host.

## Contacts and facts
The prototype uses the supplied phone number and listing facts. Reservation / order buttons start WhatsApp chats rather than pretending to process a booking or payment. The embedded map requires internet access. No unprovided email address or Telegram username was invented.

## Image note
Menu photos and interiors are illustrative AI-generated concept photographs, not verified pictures of the actual restaurant or its prepared dishes. Replace them with owner-approved original images before launch. The logo is cropped from the logo/sign image supplied in the conversation and may benefit from a high-resolution transparent original from the owner.
